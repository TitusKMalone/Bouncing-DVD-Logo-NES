# Bouncing-DVD-Logo-NES

![Preview](assets/demo.mp4)
A bouncing DVD logo for the Nintendo Entertainment System, perfect for a standby screen!

Two versions: BRB Bouncing Logo, and BRB Bouncing Logo w/ Mario

To change the color of the bouncing logo, press A.

For the Mario version, a little Mario will walk across the screen and occasionally jump. He can be killed by the moving logo. Press B to make him jump manually.
